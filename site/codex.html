Macros and commands

Popular macros, one click away

113 ready-made macros for every class and spec, plus shared ones for everyone: combat, utility, quality of life, leveling, raid and PvP. Filter by class, spec, tag or search, read what each one does, and add it to your macros.

Add it yourself

Add to account or Add to character creates the macro for you. In combat it waits until you leave it. Names stay unique, and your free slots (120 account, 30 character) are shown.

Filled in from your bags

Food, drink, potions, bandages and Healthstones are looked up in your bags, so the macro uses what you actually carry.

Spells you don't know yet

Each macro lists the spells it needs and flags the ones you haven't learned, so low-level characters know what to expect.

New in 0.3.10 · Commands

47 less-known commands and conditions, like /castsequence and [@targettarget], each with a working example to copy into the game's macro window or add in one click.

Safe by design

Macros are checked before they can be added: 255 characters at most, no /run, /script or /console. Ones that talk in chat ask first. Copy text is there when the client can't create macros.

New in 0.3.10 · Boss loot

What each boss drops

The Journal lists every boss with the items it drops, a drop chance where the list has one, and a mark on the ones RUIN members have already looted. Lists come from loot data files, so RUIN can fill in WoW Forever's real tables dungeon by dungeon; until then the Deadmines shows WoW Classic's list, clearly marked as not yet checked on Forever.

Per boss

Rhahk'Zor, Sneed, Gilnid, Mr. Smite, Captain Greenskin, Edwin VanCleef: each with its items, hover any of them for the tooltip.

What RUIN looted

"Looted 2x by RUIN" beside listed items, and anything RUIN looted that no list has yet, so the gaps fill themselves.

Open data

One simple file per set of dungeons: boss name, then item IDs. A data addon can add lists too. Verified lists say so.

Gear Path and best-in-slot lists left Codex in 0.3.10: RUIN will track gear with a dedicated gear addon.

What it does

Three answers before every run

The journal

Every dungeon's and raid's level range, where it is, and each boss with a one-line tip and its loot. Inside a dungeon, Codex opens on it, and you can plan a RUIN run for the day and time you pick.

Learned drops

When anyone in RUIN loots an uncommon or better item in a dungeon, it's added to that dungeon's list for everyone. The org builds the loot table by playing.

The upgrade line

Hover any gear and Codex compares it with what you're wearing and names the slot: "+18% upgrade over your chest", or "-8% vs your ring 2". For rings and trinkets it compares against the weaker of your two.

In the RUIN window

A journal written by the org

WoW Forever changed level ranges and added new dungeons. Codex fills in what RUIN members actually see, so the list gets better every night the org runs dungeons.
